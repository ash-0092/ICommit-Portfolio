## Rules that keep recurring

These emerged across several sessions and apply beyond EBM:

1. **One measure, one home.** Define it in one file; reference it everywhere else. Duplicated definitions drift.
2. **Declare gaps, don't omit them.** An empty-but-named row is a scope decision. A missing row looks like an oversight.
3. **Behaviour beats opinion.** A maintained workaround is a fact; reported pain is a feeling.
4. **A static row is dead weight.** If a measure can never move again, it belongs in a different artifact.
5. **The scorecard serves the investment conversation** — *should we keep funding this?* — not weekly steering, and never performance management.
6. **Every number here is a pre-launch hypothesis** until a baseline exists.
